# Follow-up application form research — 10 October 2026

Research covers the 15 routes previously marked unavailable, plus Tamil Nadu central-institution downloads. Checks used public pages, form controls, PDF downloads and published client routes. No applicant login, Aadhaar entry, declaration acceptance or submission was performed. HTTP 200 alone was not treated as proof of an application form.

| Catalogue ID | Outcome | Public evidence |
|---|---|---|
| `tg-pre-matric` | Fresh and renewal forms confirmed | [Official service list](https://telanganaepass.cgg.gov.in/PrematricLinks.jsp) links the working `tgepass.cgg.gov.in` fresh/renewal services; both return actual student form controls. Old `.do` entry failed. |
| `up-scholarship-fees` | Student registration confirmed | [Official portal](https://scholarship.up.gov.in/) publishes `RegistrationNew.aspx`; returned current 2026–27 course/category registration chooser. Service was intermittent. A harmless cache-busting query was used during one GET check, but the published canonical URL is stored. |
| `up-kanya-sumangala` | Registration/login confirmed | [Citizen entry](https://mksy.up.gov.in/women_welfare/citizen/guest_login.php) contains programme terms and registration/login form controls. Applicants must accept terms themselves. |
| `up-sant-ravidas` | Exact authenticated scheme form route confirmed | [UP Labour Department](https://uplabour.gov.in/) links `upbocw.in`, which redirects to `website.upbocw.in` and links the worker application. Applicant public JavaScript defines `/worker/scheme/sant-ravidas-shiksha` with the `SANT_RAVIDAS_SHIKSHA` multi-step form, student/worker details, documents and submit handler. The exact URL returns the application shell. Worker authentication is required; authenticated behaviour was not tested. |
| `cg-gyan-protsahan` | Student form confirmed | [Department scholarship portal](https://schoolscholarship.cg.nic.in/fhome.aspx) links `CMGyaanProtsaahanRegistration.aspx`; actual academic-year, board roll-number and student application fields are present. |
| `od-kalinga-sikhya` | Student registration route confirmed | [Higher Education Department guideline](https://dhe.odisha.gov.in/sites/default/files/2023-11/51596.pdf) directs interest-subsidy applications to the State Scholarship Portal after obtaining an education loan. The portal's student-registration route is used; the loan itself is applied for through a scheduled bank. |
| `tn-bcmbc-postmatric-college` | UMIS login confirmed | [Department forms page](https://bcw.tn.gov.in/sub_page/62) links `umisdashboard.tnega.org/auth/login`. Public authentication code contains username/password/CAPTCHA and a student role with student-dashboard navigation. Successful applicant login was not tested. |
| `pm-mudra` | Common loan and Shishu PDF forms confirmed | [Government programme publication](https://financialservices.gov.in/beta/sites/default/files/2025-04/Decade-of-Mudra-Yojana-Cover-Story-by-NIS.pdf) identifies the official programme; [Mudra Bankers Kit](https://www.mudra.org.in/Home/PMMYBankersKit) links both PDF application forms. Both downloads return PDFs. Submit completed forms to participating lenders. |
| `jh-marang-gomke` | Closed | [MGOS portal](https://mgos.jharkhand.gov.in/) states applications closed for session 2026–27 and publishes selection results. Administrative login is not a student form. |
| `jh-sc-coaching` | Institution route | [Welfare Department guidelines](https://www.jharkhand.gov.in/PDepartment/ViewDocument?id=D030DO00616012019010943594) describe grant applications by coaching institutions. Students should contact participating institutions or the department. |
| `as-combined-merit` | Unconfirmed | [Official scholarships page](https://directorateofhighereducation.assam.gov.in/portlets/scholarships) links the AMTRON service; its HTTPS endpoint has an expired certificate. No TLS bypass or insecure HTTP application is published. |
| `as-pg-research` | Unconfirmed | Same official AMTRON entry limitation. Old programme instructions do not establish a working current blank application form. |
| `wb-hindi-scholarship` | Unconfirmed | [Council scheme page](https://wbchse.wb.gov.in/student/scholarship/hindi-scholarship-scheme/) downloads an old notice for an earlier cycle, with instructions to obtain a form from the Directorate. No current public form confirmed. |
| `ap-overseas` | Unconfirmed | [Jnanabhumi](https://jnanabhumi.ap.gov.in/) public site and published client routes did not confirm a current overseas student form. No generic portal homepage or guessed route substituted. |
| `up-abhyudaya` | Unconfirmed | Published statewide Abhyudaya HTTPS portal could not be reached. [District education page](https://sonbhadra.nic.in/education/) lists older batch information; a current statewide student form was not confirmed. |
| `tn-central-institutions` (additional) | Fresh/renewal downloads confirmed | [Department forms page](https://bcw.tn.gov.in/sub_page/62) links the 2026–27 IIT/NIT fresh and renewal application PDFs; both return PDF documents. Submission remains through the institution as instructed. |

The URL policy permits only the exact verified UMIS login, Mudra PDF paths and Sant Ravidas worker form path on their respective non-`gov.in` providers; unrelated paths and query strings are rejected. Existing government route validation is retained.

It contains only public programme name/state, is not an official form URL, and cannot be substituted for one in backend AI facts.
